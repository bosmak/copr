# COPR

My [Fedora COPR packages](https://copr.fedorainfracloud.org/coprs/bosmak/copr/).

## Packages

- [pvpn](pvpn/) — Proton VPN client with TUI
- [clip-bridge](clip-bridge/) — sync X11 and Wayland clipboards seamlessly
- [steam-fix-trayicon](steam-fix-trayicon/) — Steam tray icon: double click opens the Steam window
- [solidcraft](solidcraft/) — open-source parametric 3D CAD
- [artcraft-launcher](artcraft-launcher/) — installs and updates the Craft App Suite
- [cadcraft](cadcraft/) — computer-aided design and drafting (AutoCAD-like)
- [deckcraft](deckcraft/) — presentations and slide shows (PowerPoint-like)
- [designcraft](designcraft/) — page layout and publishing (InDesign-like)
- [effectcraft](effectcraft/) — motion graphics and visual effects compositor
- [figcraft](figcraft/) — interface design and prototyping (Figma-like)
- [filmcraft](filmcraft/) — non-linear video editor
- [gridcraft](gridcraft/) — spreadsheet (Excel-like)
- [lightcraft](lightcraft/) — photo library and raw developer
- [pdfcraft](pdfcraft/) — PDF reader and editor
- [photocraft](photocraft/) — image editor (Photoshop-like)
- [soundcraft](soundcraft/) — digital audio workstation (Pro Tools-like)
- [vectorcraft](vectorcraft/) — vector illustration (Illustrator-like)
- [wordcraft](wordcraft/) — word processor (Word-like)
